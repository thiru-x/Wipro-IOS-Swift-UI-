# SwiftUI Practice

A beginner-friendly collection of SwiftUI exercises.

## Exercises
1. `01-HelloSwiftUI.swift` — Text, Image, VStack, modifiers
2. `02-CounterApp.swift` — `@State` and buttons
3. `03-ProfileCard.swift` — reusable-looking profile layout
4. `04-LoginForm.swift` — TextField, SecureField, form state
5. `05-TodoList.swift` — List, adding and deleting items
6. `06-StudentMarks.swift` — arrays, computed values, conditional UI
7. `07-ExpenseTracker.swift` — model structs, list rows, totals
8. `08-WeatherCard.swift` — cards, SF Symbols, conditional styling

## How to use
- Each file contains a standalone SwiftUI view.
- Create a new iOS App project in Xcode and replace the generated view code with one exercise at a time.
- Keep only one `@main` app entry point in the project.
- These files are practice snippets, not one app to compile all at once.
- Full SwiftUI previews and iOS Simulator require macOS and Xcode.

## GitHub upload
Create a repository named `SwiftUI-Practice`, then upload these files.
Suggested commit message: `Add beginner SwiftUI practice exercises`
